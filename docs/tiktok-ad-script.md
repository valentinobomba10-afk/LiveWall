# LiveWall — TikTok ad

Format: 9:16 vertical, 1080×1920. Target 21–24s. No talking head needed — screen capture carries it.

The whole ad is one idea: **your desktop is boring, and it takes 20 seconds to fix.**

## Shot rules

- **Hook in frame one.** No logo intro, no "hey guys". The first frame must already be the boring desktop or the moving wallpaper.
- **Never show a static screen for more than 1.5s** except the 11–14s payoff shot — that one earns its stillness because the wallpaper is moving.
- **Cursor movement should be fast and confident.** Rehearse the clicks before recording. Hesitation reads as "complicated app".
- **Cut on the beat.** The Set Wallpaper click should land exactly on the drop.
- **Vertical crop:** record the full screen, then crop to a 9:16 column centred on the app window. Don't resize the app to be tall — the UI looks wrong narrow.

## Capture setup

- OBS is already installed. Record display capture at full res, 60fps, then crop in edit.
- Or `Cmd+Shift+5` → Record Entire Screen.
- **Hide personal stuff first:** desktop icons, menu-bar items, Downloads folder, browser tabs, the LiveWall sign-up screen with your email.
- Clean the desktop to a couple of icons — clutter reads as messy and distracts from the wallpaper.
- Record each shot 3–4 times and pick the cleanest take.

## Text style

- Big, bold, centred-lower-third, white with a heavy shadow or dark pill behind it.
- 3–5 words max per card. If it takes longer than a second to read, cut it.
- Keep captions clear of the bottom ~15% (TikTok UI covers it).

## Honest-claims checklist

Do not say or imply:
- "changes your Mac wallpaper" — it draws a desktop-layer window
- "download any YouTube video" — not supported and not going to be
- a version number or feature that isn't in the build you're recording
